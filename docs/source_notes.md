## Schema changes (0.1 · สำรวจ 23 ก.ย. 69)

ใช้ DuckDB อ่านเฉพาะส่วนหัวของไฟล์ ไม่ได้อ่านข้อมูลจริง

```sql
SELECT name, count(*) AS files, min(regexp_extract(file_name,'\d{4}-\d{2}')) AS first_month
FROM parquet_schema('data/raw/yellow/*.parquet') GROUP BY name ORDER BY files;
```

**การตีความ (ยังไม่ยืนยัน):** น่าจะเป็นช่องทางที่ผู้โดยสารเรียกรถ เพราะ `HV0003` เป็นรหัสฐานผู้ประกอบการของ Uber ในข้อมูล FHVHV ของ TLC และ `EH****` มีรูปแบบเหมือนรหัสฐาน e-hail ส่วน `A` กับ `CC` ยังไม่ทราบ
**ต้องยืนยันก่อนใช้งานจริง** โดยหาเอกสาร TLC ฉบับใหม่กว่านี้ หรือหมายเหตุการเปลี่ยนแปลงข้อมูล — ห้ามนำไปสรุปในพอร์ตจนกว่าจะยืนยันได้
